Avelio Mart

A full-stack e-commerce mobile platform — shopper-facing storefront, backend API, and a merchant admin dashboard, built solo end to end.

Features

Storefront: product browsing and search, cart with quantity controls, wishlist
Checkout: bank-transfer payment flow with order-status tracking (Placed → Awaiting Payment → Confirmed)
Merchant admin dashboard: product, inventory, and order management
Backend API: RESTful endpoints with schema validation

Tech stack

Frontend: React Native
Backend: Node.js, Hono
Database: PostgreSQL, Drizzle ORM
Validation: Zod
Deployment: Cloudflare Workers

What I built

I designed and built this entire platform solo: the mobile app UI, the backend API and database schema, the checkout/payment flow, and the separate merchant admin panel for managing products, inventory, and orders.

Status

Actively maintained personal project.
